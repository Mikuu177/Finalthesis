Model Internals

Step-by-step visualization of how the lightweight classifier transforms a question into category probabilities.

Purpose: Make the small model understandable: text input, tokenization, TF-IDF vectorization, feature weights, and final category prediction.

Interactive Classifier Walkthrough

This is a pedagogical visualization. It uses fixed demo weights to show the same logic as the real TF-IDF + Logistic Regression classifier.

Demo only, not live model inference
1

Text Normalization

Lowercase text and keep the meaningful words/numbers for feature extraction.

How to read: the model does not understand grammar like a human; it converts text into a feature-friendly form.

2

Tokenization and Bigrams

The classifier uses unigram and bigram features, matching the real setting `ngram_range=(1, 2)`.

How to read: single words and adjacent word pairs can both become features.

3

TF-IDF Vectorization

Tokens are converted into a sparse numeric vector. Higher TF-IDF means the feature is more informative.

Formula shown here: TF-IDF = term frequency × inverse document frequency.

4

Feature Contributions

Logistic Regression assigns category-specific weights to features. Positive contribution pushes the sample toward that category.

How to read: this table explains why the predicted category receives a high score.

5

Category Probabilities

The category scores are converted into probabilities. Confidence is the largest probability.

How to read: if confidence is below the fallback threshold, the online system would use the safer fallback prompt.
